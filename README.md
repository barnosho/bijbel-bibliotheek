# Bijbel-bibliotheek

Downloadable translations for the personal KJV-based Bible app.

- `v1/translations` — catalogue (JSON) read by the app's translation manager
- `translations/<ABBR>.zip` — one archive per translation (USFM per book, metadata.json, optional word-study data)

All texts are public domain, except: Open Scriptures morphology (CC BY 4.0, Hebrew word study),
ETCBC Peshitta OT (CC BY-NC 4.0) and SEDRA 3 (free for non-commercial use) — personal use only.
